# GitHub 代码搜索 Star & 更新时间排序助手

在 GitHub 代码搜索结果里直接看到每个仓库的 **Star 数**、**匹配文件的最后提交日期**和**仓库更新时间**，并支持按它们排序。

## ✨ 功能

- **实时显示 Star 与日期** — 结果一出现就先挂上占位徽章，数据一到立刻就地填充，不必等所有请求完成；同一仓库的多个结果只请求一次。
- **页内排序** — 按 Star / 文件更新日期 / 仓库更新日期排序，再次点击切换升序降序；可随时恢复 GitHub 默认顺序。
- **跨页扫描汇总** — 一次扫描多页结果，按文件去重汇总（含文件路径、行号范围、Star、日期、所在页码），支持重新扫描。
- **点击跳转到匹配行** — 扫描面板里的每一行都可以点击，会在新标签页打开文件并直接定位到匹配的行号（如 `#L10-L20`）。
- **中英双语** — 界面语言自动跟随浏览器（`zh*` → 中文，其余 → 英文），也可在菜单里直接切换。
- **本地缓存** — 仓库与文件信息缓存在 `sessionStorage`（10 分钟 TTL），减少重复请求。

## 🚀 使用

1. 安装后打开 https://github.com/search?type=code 并搜索代码。
2. 每条结果标题栏右侧会出现徽章：`⭐ Star 数  📄 文件更新日期  🕒 仓库更新日期`（同一时间只显示与当前排序对应的那一个日期）。
3. 结果列表上方会出现工具栏，提供三个排序按钮、**恢复默认排序**和 **📊 扫描 N 页并汇总**。

## ⚙️ 菜单命令

在用户脚本管理器的脚本菜单中可用：

| 命令 | 说明 |
|---|---|
| ⚙️ 设置 GitHub Token | 设置 Personal Access Token，把 API 速率限制从 60 次/小时提升到 5000 次/小时 |
| 🗑️ 清除 GitHub Token | 清除已保存的 Token |
| ℹ️ 查看 Token 状态 | 查看是否已设置 Token 及当前速率限制 |
| 📄 设置扫描页数 | 设置扫描的结果页数（1–20，默认 3） |
| 🌐 界面语言 | 切换界面语言：自动（跟随浏览器）/ 中文 / English，✓ 标记当前项 |

## ⚠️ 注意事项

- 仅作用于**代码搜索**（`type=code`），不影响仓库、Issue 等其他搜索类型。
- **强烈建议设置 Token**：未设置时匿名 API 限制为 60 次/小时，且该额度在同一 IP 下的所有脚本/浏览器间共享；此外每个匹配文件还需要一次额外的 Commits API 请求来获取提交日期。
- 扫描页数越多，耗时越长、消耗的 API 配额越大。
- GitHub 若调整页面结构，可能导致结果解析失效。遇到问题欢迎在脚本页反馈。
